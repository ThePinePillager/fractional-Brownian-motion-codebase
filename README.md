# fractional-Brownian-motion-codebase

This repository contains all code used in Nathan Roe, Jacob Tannenbaum, Anna Mattson's Stochastic Processes final paper on fractional Brownian motion. 
Both the fBm_fLm and Davies_Harte files are fairly easy to understand and even easier to use, but the Noise_Map_Generator is impossible to understand and atrocious to use for anyone except Nathan. Case in point, the fake_fBm function implements actual fBm, whereas the fBm function implements fake, octave based fBm.
